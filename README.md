# Software Testing Portfolio (软件测试作品集)

> 本仓库记录了我在独立全栈开发“高校实训任务协同管理系统”过程中，作为**独立测试工程师**所完成的完整测试实操资产与测试证据。

## 🛠️ 测试技能栈
- **测试理论**：等价类划分、边界值分析、场景法、状态迁移法。
- **接口测试**：Chrome F12 抓包分析、Postman 鉴权测试 (JWT/Token)。
- **白盒测试**：JUnit 5 单元测试、边界测试数据构造、断言 (Assert) 验证。
- **数据库**：MySQL 多表查询与数据一致性校验。
- **缺陷管理**：规范化缺陷提报（前置条件、复现步骤、日志/截图）。

## 📁 目录结构说明
- **`软件测试过程材料.xlsx`**：核心测试资产表，包含以下四大模块：
  1. **功能测试用例**：覆盖登录正常流、异常边界（密码长度限制）、防爆破机制（连续5次锁定）。
  2. **接口测试用例**：记录 POST 登录获取 Token，以及 GET 请求携带 Token 鉴权的实操。
  3. **单元测试用例**：记录 JUnit 5 测试 Token 签发、防篡改、过期拦截的代码级验证。
  4. **缺陷列表**：真实提报的系统业务缺陷及外部靶场缺陷。
- **`/Screenshots`**：测试证据截图存放目录。

## 🔍 核心测试亮点
1. **接口安全与鉴权**：通过 F12 抓包提取真实接口，在 Postman 中验证了携带有效 Token 访问（200 OK）与无 Token 被拦截（401 Unauthorized）的安全机制。
2. **前端路由守卫**：通过手动清空浏览器 LocalStorage 并强行访问后台 URL，验证了前端路由重定向至登录页的逻辑。
3. **白盒防御测试**：针对 JWT 机制编写 JUnit 测试类，验证了 Token 被篡改、过期后的失效逻辑，保障了底层安全。
